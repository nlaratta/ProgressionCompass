Progression Compass — your guide through Terraria's crafting and progression.

Features:
- Optimal crafting paths for any item with full dependency trees
- Material checklist with source info (drops, shops, shimmer, events, fishing)
- Step-by-step crafting order with alternate sources and drop rates
- Gear upgrade recommendations by class (Melee/Ranged/Mage/Summoner)
- Boss progression tracking with summon hints
- Item tracking with TODO action plan and HUD overlay
- "Ready to Craft" / "Almost Ready" / "Building Toward" dashboard

Works automatically with all loaded mods (Calamity, Thorium, etc.).
Scans inventory, banks, equipment, nearby chests, and Magic Storage.

Client-side only — no server impact in multiplayer.
